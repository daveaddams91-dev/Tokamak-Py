High-performance Numba-accelerated N-body electromagnetic plasma confinement engine for tokamak physics, with Boris integration and PyQt6 visualization.

## Overview

`Tokamak-Py` is a systems-level tool featuring lexical analysis, parsing, and execution pipelines designed for efficiency and correctness.

## Features

- Modular tokenizer and parser pipeline.
- Comprehensive test suite for language grammar and runtime operations.
- Performance benchmarks evaluating throughput and memory efficiency.

## Getting Started

```bash
git clone https://github.com/rajveersinh-is-dev/Tokamak-Py.git
cd Tokamak-Py
pip install -r requirements.txt
```

Run tests:

```bash
pytest tests/
```
